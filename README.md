# Margin Shop

동대문 의류 사입 & 플랫폼별 적정 판매가 계산기. 브라우저에서만 계산하는 반응형 단일 페이지 앱입니다.

## 바로 실행

Node.js 22 이상에서 **패키지 설치 없이** 실행합니다.

```bash
npm run dev
# http://127.0.0.1:4173
```

배포 파일만 만들려면:

```bash
npm run build
```

루트 `index.html`과 `dist/index.html`이 생성됩니다. 빌드 결과는 CSS·JavaScript·SVG를 모두 포함한 단일 HTML입니다. 일반 브라우저에서 직접 열거나 `dist/`를 정적 호스팅에 올릴 수 있습니다. `file://`에서의 저장·클립보드 허용은 브라우저 정책에 따라 다르므로 실제 운영에는 HTTPS 정적 호스팅을 권장합니다. 계산 자체에는 API, 서버 함수, 계정, 데이터베이스, 런타임 CDN이 없습니다.

## 기능

- VAT 포함/별도 도매가, 삼촌비, 부자재, 계약 택배비, 고객 배송비와 무료배송 전환.
- 스마트스토어 5.8%, 에이블리 13.5%, 지그재그 12.5%, 쿠팡 윙 10.8%, 직접 입력. **요청된 예시 요율이며 최신 공식 요율이 아닙니다.** 실제 VAT 포함 실부담 요율로 수정하세요.
- 도매 공급가 × 배수 / 목표 순마진율 / 판매가 직접 입력. 직접 입력한 가격은 변경하지 않습니다.
- 100원·1,000원 반올림 또는 가장 가까운 900원 끝자리. 목표 미달 시 경고와 검증된 대안 가격.
- 판매가, 예상 순이익, 실제 마진율, 손익분기 판매가, 비용 구조, 엑셀용 탭 구분 요약 복사.
- 숫자 콤마와 중간 편집, 확인 후 초기화, 버전·범위 검증을 거친 LocalStorage, 저장 제한 안내, 복사 차단 시 수동 복사창.
- 키보드로 조작 가능한 네이티브 컨트롤, 모바일 결과 바로가기, 정적 셀러 가이드, 메타 태그, 구조화 데이터, 개인정보 안내.

## 계산 기준

판매가는 부가세 포함 상품 가격입니다. 배수의 기준은 **부가세 제외 도매 공급가**입니다. 삼촌비·부자재·택배비는 실제 결제액을 입력합니다.

```text
수수료 = 판매가 × 실부담 수수료율
  (옵션 선택 시 고객 배송비에도 같은 수수료율 적용)

부가세 추정분 = max(0, (판매가 + 고객 배송비) / 11 − 공제 가능한 매입세액)
순이익 = 판매가 + 고객 배송비 − VAT 포함 도매가 − 삼촌비
         − 부자재 − 출고 택배비 − 수수료 − 부가세 추정분
순마진율 = 순이익 / 판매가 × 100
```

일반과세자용 단순 추정입니다. 도매 매입세액 공제는 기본 반영하며 **적격증빙과 공제 요건을 충족할 때만** 적용해야 합니다. 기타 비용의 매입세액 공제는 기본 미반영입니다. 기타 공제 옵션은 삼촌비·부자재·택배·수수료가 모두 VAT 포함이며 공제 가능한 경우에만 사용하세요. 환급 예상액은 건당 이익으로 더하지 않습니다.

부가세 옵션을 끄면 세전 비교이며 간이과세자 계산이 아닙니다. 소득세·법인세, 광고, 쿠폰, 반품, 재고 손실, 인건비·임차료 등은 제외합니다. 엄밀한 회사 전체 순이익이 아닌 입력 비용 기준의 예상 기여이익입니다. 실제 세액은 세무 전문가에게 확인하세요.

그래프는 **고객 배송비를 포함한 총 결제액** 기준이며 부가세 추정분을 별도로 표시합니다. 손실일 때는 비용 합계를 기준으로 그려 음수 막대가 생기지 않습니다. 판매가 0원의 마진율은 `—`로 표시합니다. 내부 계산은 소수 정밀도를 유지하고 표시만 원 단위로 반올림합니다.

기본 예시: 사입가 15,000원(VAT 별도), 삼촌비 500원, 부자재 400원, 출고비 2,800원, 고객 배송비 3,000원, 수수료 5.8%, 배수 2.5, 900원 끝자리. **판매가 37,900원 / 예상 순이익 16,284원 / 마진율 43.0%**.

## 소스와 검증

```text
src/calculator.mjs   순수 계산·목표 역산·가격 정리·요약
src/storage.mjs      저장 스키마·화이트리스트·예외 처리
src/app.mjs          DOM 이벤트·숫자 편집·결과·대화상자
src/template.html    시맨틱 화면·정적 SEO 콘텐츠
src/*.css           기본·입력·결과·가이드·반응형 디자인
src/tailwind.css    로컬에서 미리 컴파일한 Tailwind 4.1.10
scripts/build.mjs   Node 표준 라이브러리 기반 단일 HTML 빌드
scripts/serve.mjs   개발용 정적 파일 미리보기
```

```bash
npm test             # Node 기본 테스트 러너, 38개
npm run build        # 의존성 설치 없는 재현 가능한 빌드
npm run check        # 두 작업을 순서대로 실행
```

브라우저 통합 테스트는 별도 개발 도구만 설치합니다. 앱 런타임 의존성은 아닙니다.

```bash
python -m pip install playwright==1.57.0
python -m playwright install chromium
npm run dev          # 별도 터미널에서 유지
npm run test:e2e     # Chromium 실제 origin / 저장 / 복사 / file://, 18개
```

`CHROMIUM_PATH`로 시스템 Chromium 실행 파일을 지정할 수 있습니다. `BASE_URL`의 기본값은 `http://127.0.0.1:4173`입니다.

`python e2e/dom_check.py`는 관리자 정책으로 URL 이동이 막힌 환경용 **별도 DOM 하네스**입니다. 빈 페이지에 문서를 렌더링하며 저장·클립보드를 메모리 대역으로 검사합니다. 실제 origin의 저장 권한이나 시스템 클립보드 검증을 대체하지 않습니다. 제작 환경에서 단위 테스트 38개, DOM 하네스 18개가 통과했습니다. Chromium 320·390·768·1440px의 가로 넘침과 0원·손실·매우 큰 금액, 소수·콤마 편집, 다이얼로그 키보드 동작을 검사했습니다. 실제 iOS Safari와 정적 호스팅 배포는 별도 확인이 필요합니다.

## 배포·SEO·개인정보

`npm run build` 후 `dist/`를 GitHub Pages 등 정적 호스팅에 배포하면 됩니다. 백엔드나 환경 변수는 필요하지 않습니다. CI는 테스트와 HTML 아티팩트 생성만 수행하며 자동 배포하지 않습니다.

실제 도메인이 정해지면 canonical, OG URL, sitemap을 추가하세요. 현재는 존재하지 않는 도메인·광고 게시자 ID·연락처를 넣지 않았습니다. 광고와 분석 스크립트는 없습니다. 가이드·메타 태그만으로 애드센스 승인이나 검색 순위를 보장할 수 없습니다. 광고 도입 시 개인정보 안내 및 필요한 동의 절차를 다시 확인하세요.

입력값은 현재 기기의 `margin-shop:settings:v1` 키에만 저장합니다. 공용 기기에서는 초기화하세요. 웹 호스팅 자체의 접속 로그와 외부 국세청 링크는 해당 서비스의 정책이 적용됩니다.

세액 산식 참고: [국세청 부가가치세 세액계산 흐름도](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7696&mi=2274).
Tailwind의 라이선스는 `THIRD_PARTY_NOTICES.md`에 포함되어 있습니다.
